### 4.7 SDK初始化与使用示例

```java
// ===== 1. SDK初始化（Application中） =====
EZOpenSDK.initLib(application, APP_KEY, ACCESS_TOKEN);

// ===== 2. 获取SDK实例 =====
EZOpenSDK sdk = EZOpenSDK.getInstance();

// ===== 3. 创建播放器 =====
EZPlayer player = sdk.createPlayer(deviceSerial, cameraNo);
// 或使用RTSP URL创建
EZPlayer player = sdk.createPlayerWithUrl(rtspUrl);

// ===== 4. 配置播放器 =====
player.setHandler(mHandler);
player.setSurfaceHold(surfaceHolder);
player.setPlayVerifyCode(verifyCode);  // 加密设备
player.setHardDecode(true);            // 开启硬解码

// ===== 5. 开始播放 =====
player.startRealPlay();

// ===== 6. 播放控制 =====
player.openSound();                     // 开启声音
player.closeSound();                    // 关闭声音
Bitmap bmp = player.capturePicture();   // 截图
player.startLocalRecordWithFile(path);  // 开始录像
player.stopLocalRecord();               // 停止录像

// ===== 7. 对讲 =====
player.startVoiceTalk(true);            // 开始对讲(当前设备)
player.stopVoiceTalk();                 // 停止对讲
player.setVoiceTalkStatus(pressed);     // 半双工：按下/释放

// ===== 8. 云台控制 =====
sdk.controlPTZ(deviceSerial, cameraNo,
    EZPTZCommand.EZPTZCommandLeft,       // 方向
    EZPTZAction.EZPTZActionSTART,        // 开始/停止
    EZConstants.PTZ_SPEED_FAST);         // 速度

// ===== 9. 清晰度切换 =====
sdk.setVideoLevel(deviceSerial, cameraNo,
    EZVideoLevel.VIDEO_LEVEL_HD.getVideoLevel());

// ===== 10. 电子放大 =====
player.setDisplayRegion(true, oRect, curRect);

// ===== 11. 释放播放器 =====
player.stopRealPlay();
player.release();

// ===== 12. 获取设备列表 =====
List<EZDeviceInfo> devices = sdk.getDeviceList(0, 20);

// ===== 13. 布撤防 =====
sdk.updateDefence(deviceSerial, 1);  // 1=布防, 0=撤防

// ===== 14. 退出登录 =====
sdk.logout();
```

## 五、与智能家居开放平台对接的关键能力评估

| 对接需求 | 萤石支持程度 | 说明 |
|----------|-------------|------|
| 设备管理 | ✅ 完整支持 | 设备增删改查、状态监控、通道管理 |
| 实时视频 | ✅ 完整支持 | 多协议取流(ezopen/RTMP/HLS/FLV)、多清晰度 |
| 录像回放 | ✅ 完整支持 | SD卡回放+云存储回放+云录制 |
| 语音对讲 | ✅ 完整支持 | 双向语音、增益控制、麦克风切换 |
| 云台控制 | ✅ 完整支持 | 方向/缩放/聚焦/预置位/巡航 |
| 智能分析 | ✅ 完整支持 | 移动侦测/人形/车辆/火点检测 |
| 消息推送 | ✅ 完整支持 | 设备状态+报警消息订阅 |
| 多平台SDK | ✅ 完整支持 | Web/Android/iOS/PC四端 |
| 海外部署 | ✅ 完整支持 | 6个海外区域节点 |
| IoT设备控制 | ⚠️ 有限 | 主要面向IPC/NVR等安防设备，非通用IoT协议 |
| 第三方设备接入 | ❌ 不支持 | 仅支持萤石/海康品牌设备 |

## 六、总结

萤石开放平台的核心优势在于**视频监控能力**(直播/回放/对讲/云台/智能分析)的完整性，API和SDK覆盖了从设备管理到视频消费的全链路。但在智能家居通用IoT设备控制方面能力有限，主要聚焦于安防摄像机和NVR设备。如果智能家居开放平台需要对接萤石，建议重点关注视频监控和智能分析模块的集成。
