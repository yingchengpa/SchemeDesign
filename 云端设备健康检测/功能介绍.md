# 云端设备健康检测 — 功能清单

> **版本说明**
> - ✅ **本期实现**：一、基础设备与录像健康；三、健康展示与统计
> - 🔮 **后期增值**：二、AI 图像质量与画面验证
> - ⏳ **后续规划**：四、告警与通知；五、报告体系

---

## 一、基础设备与录像健康 ✅ 本期实现

| 编号 | 功能 | 说明 |
|:---:|------|------|
| 1 | **云连接及数据上报状态检测** | 检测 IPC/NVR/VMS 与宇视云的连接状态，包括：当前连接状态、最后在线时间、最后一次数据上报时间、历史云连接在线率 |
| 2 | **设备在线状态检测** | 检测 Camera/NVR/DVR/Server 是否在线，支持设备 Uptime 历史统计 |
| 3 | **IPC 视频源检测** | 检查摄像机能否产生图像、是否有实时画面，识别 Feed Outage / Feed Not Live |
| 4 | **录像状态检测** | 检查摄像机当前是否录像、近期录像是否存在；识别录像异常、配置错误或故障；检查是否在录制音频 |
| 5 | **录像保存天数检测** | 检查实际保存天数是否达标，识别录像天数不足或缺失某些日期的录像 |
| 6 | **硬盘健康检测** | 检查 NVR/DVR/服务器硬盘状态，显示正常硬盘数量，统计 HDD OK 历史百分比 |
| 7 | **设备时间与时间戳检测** | 检查设备时钟、视频时间戳和时区是否正确，统计设备与真实时间的 Time Drift |

## 二、AI 图像质量与画面验证 🔮 后期增值

| 编号 | 功能 | 说明 |
|:---:|------|------|
| 8 | **画面模糊检测** | 检测镜头失焦、画面不清晰或 Blur 问题 |
| 9 | **画面遮挡检测** | 检测镜头或主要监控区域被遮挡（Block / Obstruction） |
| 10 | **摄像机偏转及视场变化检测** | 检测摄像机 Tilt、Displacement 或 FOV 改变，判断监控方向是否偏离预期 |
| 11 | **低照度检测** | 检测画面过暗、照明不足，导致视频证据不可用 |
| 12 | **眩光检测** | 检测强光、反射或 Glare 对画面的影响 |
| 13 | **光照变化检测** | 检测当前光照环境与正常参考画面的明显变化 |
| 14 | **其他图像异常检测** | 对无法归入以上类别的 Fault / Affected / Damaged 等异常进行标记 |
| 15 | **参考图与当前图 AI 对比** | 为每台摄像机保存参考图，获取最新图，利用 AI 比较画面清晰度和视角正确性 |
| 16 | **正常场景变化过滤** | AI 过滤季节变化及人员、车辆等临时物体经过造成的非故障变化 |
| 17 | **参考图片管理** | 允许查看、更换和维护每台摄像机的参考图片 |
| 18 | **图像人工验证状态** | 支持 Healthy / View Unverified / Dismiss / Muted 等状态，便于人工确认或忽略检测结果 |

---

## 三、健康展示与统计 ✅ 本期实现

| 编号 | 功能 | 说明 |
|:---:|------|------|
| 19 | **当前健康状态汇总** | 汇总摄像机在线数、录像比例、Retention 达标数、硬盘状态、时间状态、画面健康数和问题分类数量 |
| 20 | **历史健康性能统计** | 按日期范围统计 Device Uptime、Camera Uptime、HDD OK、Cams Live、Recording、Retention、Time Drift 和 Healthy View |
| 21 | **按设备和摄像机查看结果** | 支持按 NVR/DVR/Server 查看汇总，支持逐台摄像机查看在线、录像、Retention 和图像健康结果 |
| 22 | **静音和忽略管理** | 支持将摄像机问题设为 Muted 或 Dismissed，对应时间不纳入历史健康统计 |
| 23 | **实时健康 Dashboard** | 统一 Dashboard 显示设备状态、图像问题、活动告警、历史信息和健康趋势图 |
| 24 | **自动健康检查** | 系统持续或定期自动检查设备、录像和图像状态 |
| 25 | **按需健康检查** | 用户手动触发指定设备或摄像机的状态检查 |

## 五、报告体系 ⏳ 后续规划

| 编号 | 功能 | 说明 |
|:---:|------|------|
| 28 | **图像验证报告** | 生成包含系统汇总、问题分类、摄像机名称、参考图、最新图、健康状态和录像保存天数的报告 |
